❓ Help Guide

Step-by-step instructions on how to use this admin panel. No technical knowledge needed!

📦 How to Add a New Product

  1. Go to "My Products" from the left menu
  2. Click the gold + Add Product button (top right)
  3. Fill in the product name, category, and price
  4. Upload product photos or paste image links
  5. Click Save Product — it's now live on your website!

✏️ How to Edit a Product

  1. Go to "My Products"
  2. Find the product you want to change
  3. Click the blue Edit button
  4. Change whatever you need (name, price, photos, etc.)
  5. Click Save Product to update

🗑️ How to Delete a Product

  1. Go to "My Products"
  2. Find the product you want to remove
  3. Click the red Delete button
  4. Confirm when asked — the product will be removed from your website

🖼️ How to Upload Images

  1. Go to "My Images" from the left menu
  2. Choose where the image should go (Gallery, Product, Hero, or About)
  3. If you chose "Product", pick which product it belongs to
  4. Click "Select File(s)" and choose your photos
  5. Click Upload — done!

🔍 How to Edit SEO & Sitemap

  1. Go to "SEO & Sitemap" in the left menu
  2. Select the page you want to edit from the dropdown
  3. Update Page Title, Meta Description, Keywords, and Canonical URL
  4. Paste JSON-LD schema in the Schema field (optional)
  5. Click Save SEO Settings — changes go live immediately
  6. Sitemap auto-publishes when you save — no manual upload needed
  7. Run storage setup SQL in complete-setup.sql once if publish fails

📧 Fix "Email Rate Limit" on Customer Signup

If customers see "email rate limit exceeded" when creating an account, do this once in your Supabase Dashboard:
1. Go to Authentication → Providers → Email
2. Turn OFF the "Confirm email" toggle
3. Click Save

Customers can then sign up and log in instantly — no verification email needed.

To manually confirm a stuck user, run in SQL Editor (change the email):
UPDATE auth.users SET email_confirmed_at = now() WHERE email = 'customer@email.com';

🔑 Login Credentials

Your admin panel is now secured with Supabase Authentication! The password is no longer stored in the website code.
To change your password or add new admin users, you need to go to your Supabase Dashboard:
1. Select your project
2. Click on Authentication (the users icon on the left)
3. Here you can add new users (Email/Password) or send password reset emails.

Security Note: Make sure you have Row Level Security (RLS) enabled on your 'images' table in Supabase so that only authenticated users can make changes to your database.
